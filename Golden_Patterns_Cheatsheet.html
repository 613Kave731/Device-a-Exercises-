🔴 Exercise 1 — Thévenin Equivalent with a Dependent Source Source-Transform + Millman
📐 The Golden Pattern (this is exactly what you did, confirmed correct)
1
Look for a current source in parallel with a resistor (here: IA ∥ R₁). This is always convertible.
2
Source-transform it: IA ∥ R₁ → a voltage source of value I_A·R_1 in series with R₁ (resistance unchanged, only the source type changes).
3
Now every branch feeding the A-B path is a series E + R branch. If two such branches land on the same node, combine them with Millman (see diagram below for E_m, R_m).
4
Since A-B is open (no current flows when finding VTH), all the series EMFs just add directly — no IR drops to worry about. V_TH and R_TH follow immediately (see diagram).
✅ Confirmed against your notes: V_TH = E_m + I_A·R_1, R_TH = R_m + R_1 (R_m shown above) — this is exactly the source-transform-then-add-in-series result. Your method was right.
⚠️ Where a Dependent Source Changes the Story
★
Source transformation and plain series-addition only work for the independent-source part of the network.
★
If a dependent source (like αI₁) sits inside the reduced network (not killed), you cannot just add it into V_TH by inspection — you need the V_test method: kill all independent sources only, apply a test source V_t at A-B, express the controlling variable (I₁) in terms of V_t, solve for I_t, then R_TH = V_t / I_t.
❌ Never kill a dependent source when computing R_TH. Only independent V/I sources get killed (V→short, I→open). The dependent source ALWAYS stays active.
💡 Decision rule: if the dependent source sits cleanly outside the part you're reducing (in series, away from where the controlling variable is measured), source-transform + Millman is faster. If it's tangled inside the network with its controlling variable, use V_test.
🔁 Exercise 2 — Mesh Analysis with a Dependent Source Matrix Modification Rule
📐 The Golden Pattern — confirmed from your June 2026 exam answer
1
Build the R matrix exactly like a normal mesh problem first — pretend the dependent source isn't even there. Diagonal = ΣR in that mesh, off-diagonal = −R shared.
2
Find which branch carries the controlling variable. Two cases:
• If that branch belongs to only one mesh → controlling current = that mesh current directly (e.g. I₁ = i₁, your exam's case).
• If the branch is shared by two meshes → controlling current = difference of the two mesh currents (e.g. I_x = i_m − i_n).
3
Write the dependent source term into the KVL of whichever mesh's loop contains it, then move it from the source vector to the matrix side.
4
Result: only ONE row of the matrix changes
— the row for the mesh whose KVL contained the dependent source. That row picks up an extra ±α term in the column matching the controlling mesh current.
✅ Your Exact Worked Example (verified)

Your matrix had a CCVS αI₁ in mesh 2's loop, with I₁ = i₁ directly (simplest case — controlling branch belongs only to mesh 1).

R₁+R₂+R₃−R₃−R₂i₁=E₁−E₂−E₃
−R₃ + αR₃+R₅0i₂=E₃
−R₂0R₂+R₄i₃=+E₂
✅ Notice row 2, column 1 changed from −R₃ to −R₃+α — and nothing else changed. Row 1 and row 3 are untouched. This confirms the rule: the dependent source touches exactly one cell (or one row if the controlling variable is a difference of two mesh currents, touching two cells in that row).
❌ The matrix is no longer symmetric once a dependent source is present (R₂₁ ≠ R₁₂ here: −R₃+α ≠ −R₃). Don't "fix" this — it's supposed to happen. Symmetry only holds for passive resistor-only networks.
💡 Sanity check on exam day: after adding the dependent source term, if your matrix is still perfectly symmetric, you forgot to include it. Asymmetry is your confirmation that you did it right.
🔌 Exercise 3 — Op-Amp / Millman (Two-Stage, Non-Grounded V−) Method 2 = Pure Millman ⭐
🧩 What makes this exam's circuit tricky

In your exam, the non-inverting input (V+) of each op-amp is not grounded — it's tied directly to a source (E₂ for stage 1, a Millman-combo of E₃/R₅ and E₄/R₆ for stage 2). The classical lecture method splits this into an "inverting" gain term plus a "non-inverting" gain term and adds them by superposition. It works — your numbers prove it — but it's two formulas to remember and apply correctly.

Method 1 — Superposition (what you used)
V_o = (−R_f/R_in)·V_Millman 
   + (1+R_f/R_in)·V₊

Two separate gain formulas (inverting + non-inverting), added together. Correct, but you have to remember both formulas and which one multiplies which source.

Method 2 — Pure Millman ⭐ (your preference)

ONE equation. Solve directly for V_o. No separate formulas to juggle.

📐 The Golden Pattern — Method 2 step by step
1
Find V+ first. If the + pin connects straight to ground → V+=0. If it connects straight to a single source → V+ = that source. If it has its own resistor network with multiple sources → compute V+ via its own Millman.
2
Virtual short: V− = V+ (use the real value from step 1 — don't assume it's zero).
3
Write ONE Millman equation at the V− node, including every branch touching it — input branches AND the feedback branch (treat V_o through R_f exactly like any other E/R branch), then solve for V_o. Full picture below:
✅ This collapses to the standard summing-amplifier formula V_o = −R_f·Σ(E_k/R_k + I_k) automatically whenever V+=0 — Method 2 is a strict generalization, not a different formula. You only need ONE formula for every op-amp problem on the exam, grounded or not.
✅ Verified against YOUR circuit (both stages, formula match confirmed)

Stage 1 — V+ = E₂ directly, input branch = Millman of (E₁,R₁) and (I_A), R_in=R₁∥R₂, feedback R₃:

V₋ = E₂  →  E₂ = V_Millman/R_in + V_A/R₃1/R_in + 1/R₃

⟹   V_A = (1+R₃/R_in)·E₂ − (R₃/R_in)·V_Millman

↳ Algebraically identical to your Method-1 formula. Same answer, one less formula to memorize.

Stage 2 — V+ = Millman of (E₃,R₅) and (E₄,R₆), input branch = V_A through R₇, feedback R₈:

V_o = (1+R₈/R₇)·Millman(E₃,R₅,E₄,R₆) − (R₈/R₇)·V_A

↳ Same structure, same result as your written solution. (Per your note — not re-doing the arithmetic, just confirming the method.)

❌ Biggest trap with Method 2: forgetting that 1/R_f belongs in the denominator sum too (it's a branch like any other). Leaving it out gives you the wrong V_o by a scale factor.
🖥️ Exercise 4 — ODE → Op-Amp Circuit Confirmed + Multi-Forcing-Term

1
You correctly isolated: v̈_o = 4v̇_o − 2v_o + 4sin(4t) − 2sin(6t), then built: Integrator1 (output −v̇_o) → feeds back with gain 4 into the summer, plus Integrator2 (output −v_o, via inverter chain) feeding gain 2, plus two separate forcing branches for the two sine terms.
★
New pattern vs. the single-forcing-term exams
: when the ODE has two independent forcing functions (here sin(4t) and sin(6t)), each gets its own dedicated input resistor into the summer — they are NOT combined into one branch, because they're independent signals with different frequencies/sources.
★
Gain for each forcing branch = R_f / R_branch = the coefficient of that term in the rearranged ODE. Here: gain 4 for the sin(4t) branch, gain 2 for the sin(6t) branch (sign handled by which integrator output — direct vs inverted — you tap into).
✅ Your hand-drawn circuit (summer + 2 integrators + inverters, RC=1s, two independent forcing branches) matches the standard pattern exactly. This generalizes cleanly: N forcing terms = N separate summer input branches, no matter how many there are.
📐 Quick-reference recipe (same as your blitz sheet, restated)
1
Isolate the highest derivative on the left: ÿ = −a·ẏ − b·y + f₁(t) + f₂(t) + ...
2
Chain: ÿ → Integrator1 → (−ẏ) → [use directly with gain a, OR invert first if sign needs flipping] → Integrator2 → (−y) → same sign logic for gain b.
3
Each forcing term f_k(t) gets its own resistor into the summer with gain = R_f/R_k = its coefficient, sign-corrected by whether you feed +f_k or −f_k.
4
All integrators: pick R=1Ω, C=1F (or any pair with RC=1s) — never assign separate numeric values unless the exam explicitly asks.
🔋 RL & RC Natural Decay — the Exam's Real Exercise 3 Pure Decay Shortcut
🧩 Why this exact past-exam wording is the easy version

Look at how both past papers phrase it: "RL circuit, R=10Ω, L=0.1H. Compute i_L(0.2ms), given i_L(0)=6A" — and the other: "R=0.5mΩ, L=0.5H, i_L(0)=5A, find i_L(200μs)." No E, no I, no switch, no second circuit to redraw. That absence is the tell: nothing is driving the loop after t=0, so the inductor (or capacitor) just bleeds its stored energy into the resistor on its own. That means x(∞) = 0 automatically — you skip the entire "find the post-switch steady-state circuit" step that the harder transient problems require.

📐 The Golden Pattern
1
Check for a source. If the problem only gives you R, L (or C), and one initial value — no E, no I — then x(∞) = 0. Don't draw or analyze any steady-state circuit; there's nothing to analyze.
2
Compute τ:   RL circuit → τ = L/R   |   RC circuit → τ = R·C.
3
Plug straight into the one-term decay formula below — no addition, no subtraction, just one exponential times the initial value.
4
Compute t/τ first (convert ms/μs to seconds so units match), then e^(−t/τ), then multiply by the initial value.
✅ Worked example 1 — straight from a past Messina paper

RL circuit, R = 10 Ω, L = 0.1 H, i_L(0) = 6 A. Find i_L(0.2 ms).

1
No source given → i(∞) = 0.
2
τ = L/R = 0.1/10 = 0.01 s = 10 ms
3
t/τ = 0.2ms / 10ms = 0.02
4
i(0.2ms) = 6 · e^(−0.02) ≈ 6 × 0.9802 ≈ 5.88 A
✅ Barely decayed — 0.2ms is a tiny slice of a 10ms time constant. That ratio (t/τ ≪ 1) is your built-in sanity check: if t is much smaller than τ, the answer should land close to the initial value, not near zero.
✅ Worked example 2 — same pattern, a τ that's enormous

RL circuit, R = 0.5 mΩ, L = 0.5 H, i_L(0) = 5 A. Find i_L(200 μs).

1
No source given → i(∞) = 0.
2
τ = L/R = 0.5 / 0.0005 = 1000 s — a tiny R makes τ huge.
3
t/τ = 200μs / 1000s = 2×10⁻⁷ — essentially zero.
4
i(200μs) = 5 · e^(−2×10⁻⁷) ≈ 5.00 A (unchanged to 6 decimal places).
💡 Don't panic when a tiny resistance gives you a giant τ — it just means the answer is "basically i(0)" because the exam is testing whether you notice t≪τ, not whether you can grind through a near-zero exponent.
⚠️ Don't fall for this
❌ If a problem DOES mention a source still connected after t=0 (an E or I that isn't switched out), you're back to the full formula x(t)=x(∞)+[x(0)−x(∞)]e^(−t/τ) from the main Transients exercise page — you have to actually find x(∞) from the post-switch steady-state circuit. This shortcut only applies when nothing is driving the circuit going forward.
📋 Master Cheat Sheet — Dependent Sources & Millman
Mesh + Dependent Source
Build normal R matrix → add α term only in the row of the mesh containing the dependent source
Column = whichever mesh current the controlling variable equals (or the difference of two, if shared branch). Matrix becomes asymmetric — that's correct.
Node + Dependent Source
Same idea: add the dependent term only to the row (node KCL) where it physically appears
Controlling variable = a node voltage (VCVS/VCCS) or a branch current expressed via node voltages (CCVS/CCCS).
Thévenin + Dependent Source
Kill independent sources ONLY. Use V_test if dependent source is tangled in; use source-transform+Millman if it's cleanly separable
R_TH = V_test/I_test. Never kill the dependent source — ever.
⭐ Millman Master Formula (Method 2)
V₋ = V₊, then ΣE_k/R_k + ΣI_k + V_o/R_fΣ1/R_k + 1/R_f → solve for V_o
Works whether V+ is grounded or tied to a source. One formula replaces "inverting" + "non-inverting" + superposition. Full diagram in Ex.3 above ↑
Source Transformation
I ∥ R ⟷ (I·R) in series with R
Resistance never changes in a source transform — only the source type and its series/parallel position.
Sign of Independent Sources (KVL)
Walk your mesh direction. Hit − terminal first → +E. Hit + terminal first → −E.
Draw the mesh arrow before assigning any signs — don't try to do it from memory mid-equation.
