① The Circuit — What We Are Solving

📋 Circuit Values

E = 12 V (independent voltage source)
R₁ = 4 Ω (series with E)
R₂ = 4 Ω (node N to ground)
CCCS = 2·Iₓ ↑ (into node N)
Iₓ = current through R₁ from left → right

Find: V_TH, R_TH, I_N at terminals A-B
🔴 The KEY rule before we start:
The dependent source 2Iₓ can NEVER be killed.
It stays active in every single step.
Killing it gives completely wrong R_TH.

Only the independent source E = 12V gets killed when finding R_TH.

② Find V_TH — Open Circuit, All Sources Active

1
Open terminals A-B. No current leaves through terminal → terminal current = 0.
2
Express Iₓ: Iₓ = (12 − V_N) / 4  (current through R₁ into Node N)
3
KCL at Node N — currents INTO Node N = currents OUT of Node N:
Iₓ  +  2Iₓ  =  V_N / R₂
( from R₁ ) + ( CCCS into N ) = ( through R₂ to ground )
4
Substitute Iₓ:
3 · (12 − V_N)/4 = V_N/4
3(12 − V_N) = V_N
36 − 3·V_N = V_N
36 = 4·V_N
V_TH = V_N = 36/4 = 9 V
✅ Sanity check: Iₓ = (12−9)/4 = 0.75A  |  CCCS = 2×0.75 = 1.5A  |  via R₂ = 9/4 = 2.25A  |  KCL: 0.75+1.5 = 2.25 ✓

③ Kill E — Apply V_test — Setup for R_TH

1
Kill E: replace 12V source with a wire (short circuit). Left node L is now grounded (0V).
2
Apply V_test at terminal A = Node N. B = ground. I_test is the current drawn FROM A.
3
Dependent source 2Iₓ stays active. Its value now depends on V_test via Iₓ.
🔴 Iₓ flips direction!

Before (E active): E pushed current left→right through R₁, so Iₓ was positive into N.

Now (E dead, L=0V): V_test at N pushes current from N back through R₁ to ground.

Iₓ = (V_L − V_N)/R₁ = (0 − V_test)/4 = −V_test/4

④ Find R_TH = V_test / I_test

1
Express all currents in terms of V_test:
Iₓ = −V_test/4  (re-derived after killing E — current flows N→L)
2Iₓ = −V_test/2  (CCCS value — negative = actually leaving N downward)
2
List every current LEAVING Node N:
• Via R₁ to L(=0V): V_test/4 (leaving N)
• Via R₂ to ground: V_test/4 (leaving N)
• Via CCCS = 2Iₓ = −V_test/2 (negative INTO = positive LEAVING): +V_test/2 leaving N
3
KCL at Node N: all current injected by V_test must equal all current leaving
I_test = V_test/4  +  V_test/2  +  V_test/4
via R₁     via CCCS     via R₂
4
Combine fractions:
I_test = V_test · (1/4 + 2/4 + 1/4) = V_test · (4/4) = V_test
R_TH = V_test / I_test = V_test / V_test = 1 Ω
✅ Without the dependent source: R_TH would simply be R₁‖R₂ = 4‖4 = 2Ω.
The 2Iₓ CCCS added extra current flow → more I_test for same V_test → halved R_TH to 1Ω.
This is exactly why you cannot ignore or kill the dependent source.
⚡ Units check: R_TH = V_test/I_test → Volts/Amps = Ohms ✓
R_TH can be negative in some circuits with dependent sources — that is physically valid (energy is supplied). Here it is positive (1Ω) which is also valid.

⑤ Complete Results — Thévenin + Norton

Thévenin Voltage
V_TH = 9 V
Open-circuit voltage at A-B
Thévenin Resistance
R_TH = 1 Ω
V_test / I_test method
Norton Current
I_N = 9 A
I_N = V_TH / R_TH = 9/1

⏱ Exam Speed Checklist — Dependent Source Thévenin

✅
Step 1: Open A-B, keep ALL sources active → KCL at loaded node → solve for V_TH
✅
Step 2: Write "2Iₓ stays active" next to the dependent source on your exam sheet
✅
Step 3: Kill only INDEPENDENT source(s) → apply V_test at A, B=ground
✅
Step 4: Re-express Iₓ in terms of V_test (it will change sign!)
✅
Step 5: KCL at node → solve for I_test → R_TH = V_test/I_test
✅
Step 6: Norton: I_N = V_TH / R_TH. Never recalculate R_N — it equals R_TH always.
❌
NEVER kill the dependent source. NEVER use resistor combinations alone when a dependent source is present.
