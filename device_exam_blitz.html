📋 Cheat Sheet — Walk In Knowing These Cold 12 formulas
🔥 G Matrix — Diagonal
Gii = Σ all conductances at node i
Sum ALL G = 1/R values touching node i. Off-diagonal Gij = −G between i and j (ALWAYS negative).
🔥 R Matrix — Diagonal
Rii = Σ all resistances in mesh i
Off-diagonal Rij = −R shared between mesh i and j. Source vector: +E if aids clockwise current.
🔥 Millman / Op-Amp (EVERY EXAM)
Vo = −Rf·(E₁/R₁ + E₂/R₂ ± I·Rf)
V₋ = V₊ = 0 (virtual ground). KCL at node A → set numerator = 0. Solve for Vo.
🔥 RL Transient (appears every exam)
iL(t) = iL(∞) + [iL(0)−iL(∞)]·e^(−t/τ)
τ = L/Rth. At t=∞: inductor = SHORT. At t=0: current cannot jump. Find Rth by killing sources.
RC Transient
vC(t) = vC(∞) + [vC(0)−vC(∞)]·e^(−t/τ)
τ = RC. At t=∞: capacitor = OPEN. At t=0: voltage cannot jump.
🔥 Analog Computing (ODE Circuit)
d²y/dt² = −a·dy/dt − b·y + f(t)
RC=1s. 2 integrators + 2 inverters + 1 summer. Feed back ẏ (gain a) and y (gain b) to summer.
Thevenin Voltage VTH
VTH = Voc (open circuit voltage at A-B)
Leave A-B open. Solve the circuit normally. VTH is the voltage across the open terminals.
Thevenin Resistance RTH
Kill sources (V→short, I→open). Rth = resistance seen at A-B.
With dependent sources: use V_test method. Apply Vt at A-B, find It, Rth = Vt/It.
Two-Stage Op-Amp Cascade
Solve Stage 1 → get Vo1 → feed into Stage 2
Each stage is independent. Vo1 becomes the input source for Stage 2. Two inversions = positive gain.
HOT RL Values (appear twice)
R=10Ω, L=0.02H → τ=2ms
iL(1ms) = iL(0)·e^(−0.5). Also: R=100Ω, L=0.01H → τ=0.1ms. R=1000Ω, L=0.01H → τ=10μs.
HOT RC Values
R=1Ω, C=0.1F → τ=0.1s
vC(200ms) = vC(∞) + [vC(0)−vC(∞)]·e^(−2). Also: R=10Ω, C=0.2mF → τ=2ms.
HOT ODE Forms
d²y/dt² + 4dy/dt + by = f(t)
Coefficient "4" on dy/dt appears in 4+ exams. Always 2nd order. RC=1s means R×C=1Ω·F.
📐 Exercise 1A — Node Analysis (G Matrix) 🔥 8/10 exams
Q1 HOT — 8 exams
Write the G matrix in analytical form for a 3-node circuit with nodes A, B, C (reference D).
This is part (a) of Exercise 1 in almost every exam. The circuit has resistors R₁…R₅ connecting nodes and voltage/current sources.
Method — G Matrix Construction
1
Label all nodes A, B, C with reference D (ground). Convert all resistors to conductances: Gk = 1/Rk.
2
Diagonal Gii = sum of ALL conductances connected to node i (regardless of where they go).
3
Off-diagonal Gij = Gji = −(conductance directly between node i and node j). Always negative.
4
Source vector bi: current source flowing INTO node i = +I. Flowing OUT = −I. Voltage source from node to ground: that node is KNOWN (remove its row, substitute value).
[G]·[V] = [b]
⎡ GAA GAB GAC ⎤ ⎡ VA ⎤ = ⎡ bA ⎤
⎢ GBA GBB GBC ⎥ ⎢ VB ⎥ = ⎢ bB ⎥
⎣ GCA GCB GCC ⎦ ⎣ VC ⎦ = ⎣ bC ⎦
❌ TRAP: Off-diagonal is ALWAYS negative. Students write +G instead of −G. GAB = −G between A and B, never positive.
💡 SPEED: Diagonal = "all roads from this node". Off-diagonal = "the road between these two nodes, negated".
Q2 HOT — Jan 2022, May 2023, Dec 2021, June 2022
Compute the node voltages VA, VB using: R₁=2Ω, R₂=3Ω, R₃=4Ω, R₄=2Ω, α=2S, I₁=1A, I₂=−2A.
Part (b): substitute the numerical values into the G matrix from part (a) and solve. [May 2023 exact values]
Method — Substitute and Solve
1
Compute all conductances: G₁=1/2, G₂=1/3, G₃=1/4, G₄=1/2 S.
2
Build the matrix. Diagonal: GAA = G₁+G₂+G₃ (all G at A). GBB = G₃+G₄ (all G at B).
3
Off-diagonal: GAB = GBA = −G₃ = −1/4.
4
Solve 2×2 system: multiply through by LCM to eliminate fractions. Use substitution or Cramer's rule.
❌ If α (dependent source) appears: it modifies one off-diagonal entry. α adds to the G matrix. Don't forget it!
Q3 Supernode variant — June 2022, Dec 2021
A voltage source exists between two unknown nodes (supernode). How do you handle this in the G matrix?
Supernode Method
1
A voltage source between nodes i and j = SUPERNODE. You can't use the normal KCL for either node separately.
2
Merge the two rows: write ONE combined KCL for the boundary of the supernode (currents leaving the supernode = currents entering).
3
Add constraint equation: Vi − Vj = E (voltage source value).
4
Now you have the same number of equations as unknowns. Solve.
❌ Forget the constraint equation → 1 equation, 2 unknowns → unsolvable. ALWAYS add Vi − Vj = E.
🔁 Exercise 1B — Mesh Analysis (R Matrix) 🔥 6/10 exams
Q4 HOT — Feb 2022, June 2022, Sept 2023, Dec 2022
Write the R matrix in analytical form for a circuit with 3 mesh currents I₁, I₂, I₃ (all clockwise).
Method — R Matrix Construction
1
Draw ALL mesh currents CLOCKWISE (I₁, I₂, I₃). This makes all off-diagonals negative.
2
Diagonal Rii = total resistance in mesh i (sum of ALL resistors in that mesh).
3
Off-diagonal Rij = −(resistance shared between mesh i and mesh j). Always negative if currents are both clockwise.
4
Source vector bi: walk clockwise around mesh i. +E if source aids you (+ terminal first), −E if it opposes.
⎡ R₁₁ −R₁₂ 0 ⎤ ⎡ I₁ ⎤ = ⎡ b₁ ⎤
⎢ −R₂₁ R₂₂ −R₂₃ ⎥ ⎢ I₂ ⎥ = ⎢ b₂ ⎥
⎣ 0 −R₃₂ R₃₃ ⎦ ⎣ I₃ ⎦ = ⎣ b₃ ⎦
❌ Source vector sign is the #1 error. Walk clockwise: if you hit the − terminal of a source first, the source is AIDING → +E. If + terminal first → −E.
Q5 HOT — Feb 2022 exact: R₁=4Ω, R₂=6Ω, R₃=4Ω, E₁=2V, E₂=−5V, E₃=4V, n=2
Compute I₁, I₂, I₃ for: R₁=4Ω, R₂=6Ω, R₃=4Ω, R₄=8Ω, R₅=n·R₁=8Ω, E₁=2V, E₂=−5V, E₃=4V.
This exact parameter set appears in the Feb 2022 exam. High probability of similar values.
Method
1
Build R matrix with given values. The 3×3 system gives I₁, I₂, I₃.
2
Use substitution or Cramer's rule. Multiply rows by LCM to get integer coefficients before solving.
3
Verify: write KVL for one mesh and check it balances.
❌ n=2 in the problem means R₅=2×R₁. Substitute n before building the matrix, not after.
Q6 Supermesh variant — Sept 2023, June 2022
A current source exists between two meshes (supermesh). Write the combined KVL and constraint equation.
Supermesh Method
1
Current source between meshes i and j = SUPERMESH. Cannot write separate KVL for either mesh.
2
Outer KVL: write KVL around the combined outer loop, skipping the current source branch.
3
Constraint: Ij − Ii = IS (if source flows from i-mesh side to j-mesh side).
❌ Direction of IS matters. If IS flows from mesh 1 to mesh 2: I₂ − I₁ = IS. Draw the arrow carefully.
🔌 Exercise 2 — Op-Amp / Millman Theorem 🔥 10/10 exams — GUARANTEED
Q7 HOT — EVERY SINGLE EXAM (10/10)
Write the analytical expression of Vo as a function of the input sources (E₁, E₂, I₁, etc.).
Part (a) always asks for the symbolic expression first. This is the formula derivation using virtual short + Millman.
Golden Rules + Millman Method
1
Virtual Short: V₋ = V₊. Since V₊ = 0 (grounded), V₋ = 0. Node A (inverting input) is at virtual ground.
2
Virtual Open: I₋ = I₊ = 0. No current enters the op-amp terminals.
3
KCL at Node A: Σ currents into A = 0. Each branch: (Ek − 0)/Rk flows into A. Feedback: (Vo − 0)/Rf flows into A. Current source Ik adds directly.
Vo = −Rf · (E₁/R₁ + E₂/R₂ + … ± Ik)
4
Sign of current source: INTO node A = + in KCL, so it appears +Ik in the Vo formula.
❌ Current source OUT of node A → appears as +Ik in the formula (because KCL: into = +, but the formula has a − sign from the inverting sum).
💡 Shortcut: Vo = −Rf × (numerator of Millman). Numerator = Σ(Ek/Rk) ± Σ(Ik).
Q8 HOT — Feb 2022: R₁=2Ω, R₂=1Ω, R₃=10Ω, R₄=5Ω, I₁=2A, E₁=14V
Compute the numerical value of Vo: R₁=2Ω, R₂=1Ω, Rf=10Ω, R₄=5Ω, I₁=2A, E₁=14V.
Recurring parameter set from Feb 2022. Very high chance similar values appear.
Numerical Computation
1
Use the formula: Vo = −Rf·(E₁/R₁ + E₂/R₂ ± I·Rf_branch)
2
Substitute: Vo = −10·(14/2 + I₁_contribution + ...) = calculate step by step.
3
Also find I_Rf (current through feedback resistor): I_Rf = (0 − Vo)/Rf = −Vo/Rf
❌ Part (c) asks for "I_Rf4" or similar — compute AFTER finding Vo. Use Ohm's law on each branch with known node voltages.
Q9 HOT — Two-stage cascade: June 2022, May 2023, Sept 2023, Nov 2024
Two-stage op-amp cascade: find VA and Vo. Stage 1 output becomes input to Stage 2.
Appears in ~5 of the 10 exams. The circuit shows two op-amps in series.
Two-Stage Method
1
Solve Stage 1 independently. Apply virtual ground at its inverting input. Find Vo1 (= VA often).
2
Vo1 becomes an input source for Stage 2. Treat it exactly like E₁ feeding Stage 2 through its input resistor.
3
Apply Millman to Stage 2: Vo = −Rf2·(Vo1/R_in2 + other inputs).
4
Two inversions = net non-inverting: if Vo1 = −kX, then Vo = +k'X. Check the signs.
❌ Don't use the output of Stage 2 as the feedback of Stage 1. Each stage is independent. Vo1 is NOT Vo.
💡 Two-stage cascade: solve LEFT to RIGHT. VA first, then Vo. Never mix the two stages.
Q10 HOT — Nov 2024, May 2023: R₁=1Ω, R₂=5Ω, R₃=10Ω, R₄=5Ω, R₅=100Ω, R₆=2Ω, I₁=1A
Two-stage: compute VA and Vo analytically, then compute with R₁=1Ω, R₂=5Ω, Rf1=10Ω, R₄=5Ω, Rf2=100Ω, I₁=1A.
Stage 1 → Stage 2
1
Stage 1: VA = −Rf1·(E₁/R₁ + I₁·(some path)). Compute VA numerically.
2
Stage 2: Vo = −Rf2·(VA/R₄). Substitute VA from Step 1.
3
The current source I₁ in the first stage: if it flows INTO node A, add +I₁ to numerator. If OUT, add −I₁.
🔴 Exercise 2 (variant) — Thévenin Equivalent ⚡ 4/10 exams
Q11 Jan 2022, Sept 2023, Dec 2021, June 2023
Find the Thevenin equivalent circuit at terminals A-B: find VTH and RTH analytically.
Thévenin Step-by-Step
1
VTH = Voc: open-circuit A-B, solve the circuit. VTH = voltage across the open terminals. Use node analysis or voltage divider.
2
RTH: kill ALL independent sources (V→short circuit, I→open circuit). Find resistance "looking in" from A-B.
3
If dependent sources: use V_test method. Apply Vt at A-B, find It = current from +Vt into circuit. RTH = Vt/It.
4
Norton: IN = VTH/RTH, RN = RTH. Always related by source transformation.
❌ Do NOT kill dependent sources. Only kill independent V and I sources. Dependent sources stay in the circuit always.
Q12 Jan 2022: R₁=5Ω, R₂=1Ω, R₃=2Ω, E=2V, I=1A. Also Dec 2021 variant.
Compute VTH and RTH for the circuit with: R₁=5Ω, R₂=1Ω, R₃=2Ω, E=2V, I=1A.
Numerical Thevenin
1
Open A-B. Use node analysis to find voltage at the open terminal. That's VTH.
2
Kill sources (E→short, I→open). Find R seen at A-B = RTH. Usually involves parallel/series combinations.
3
Norton: IN = VTH/RTH.
⚡ Exercise 3 — First-Order Transients (RL & RC) 🔥 10/10 exams
Q13 HOT — Universal formula for ALL transients
Write the universal transient formula and explain how to find x(0), x(∞), and τ.
The Universal Formula
x(t) = x(∞) + [x(0) − x(∞)] · e^(−t/τ)
1
x(0): initial condition. Capacitor V and inductor I CANNOT jump. For iL: use t<0 circuit with L=short. For vC: use t<0 circuit with C=open.
2
x(∞): final steady state. Use t>0 circuit. C=open (blocks DC), L=short (wire at DC). Solve the simplified circuit.
3
τ: time constant. Kill all independent sources in t>0 circuit. Find Rth seen by L or C. τ=L/Rth (RL) or τ=RthC (RC).
❌ THE #1 EXAM TRAP: Using t<0 circuit for x(∞) or τ. ALWAYS use the t>0 circuit (after the switch changes) for both x(∞) and τ.
💡 "0 from before, ∞ and τ from after." The initial condition is the only thing that uses the old circuit.
Q14 HOT — Appears TWICE with identical values: R=10Ω, L=0.02H, iL(0)=2A
RL circuit: R=10Ω, L=0.02H. Compute iL(1ms) given iL(0)=2A.
This EXACT problem appeared in two different exam years. Memorise the answer.
HOT Problem — Memorise This Answer
1
τ = L/R = 0.02/10 = 0.002 s = 2 ms
2
x(∞) = 0 (no source after switch opens — energy decays). x(0) = 2A (given).
3
iL(t) = 2·e^(−t/0.002)
iL(1ms) = 2·e^(−0.001/0.002) = 2·e^(−0.5) ≈ 2 × 0.6065 ≈ 1.21 A
💡 τ=2ms, t=1ms → exponent is −0.5 → e^(−0.5)≈0.607. MEMORISE: 2×0.607 = 1.21A
Q15 HOT — June 2022, May 2023: R=10Ω, L=0.1H, iL(0)=6A or 1A
RL circuit: R=10Ω, L=0.1H. Compute iL(0.2ms) given iL(0)=6A.
Working
1
τ = L/R = 0.1/10 = 0.01 s = 10 ms
2
iL(0.2ms) = 6·e^(−0.0002/0.01) = 6·e^(−0.02) ≈ 6×0.980 ≈ 5.88 A
❌ Convert time units carefully. 0.2ms = 0.0002s. τ in seconds. Don't mix ms and s.
Q16 HOT — RL with voltage source: R=100Ω, L=0.01H, E=2V, iL(0)=5A
RL circuit with voltage source E=2V, R=100Ω, L=0.01H. Write iL(t) and compute iL(0.5ms). iL(0)=5A.
This type appears in Nov 2024, Nov 2023 exams. Voltage source means iL(∞) ≠ 0.
RL with Non-Zero Final Value
1
τ = L/R = 0.01/100 = 0.1ms = 0.0001s
2
x(∞) = E/R = 2/100 = 0.02A (at DC steady state, L=short, V=IR)
3
x(0) = 5A (given)
iL(t) = 0.02 + (5 − 0.02)·e^(−t/0.0001) = 0.02 + 4.98·e^(−10000t)
4
iL(0.5ms) = 0.02 + 4.98·e^(−0.0005/0.0001) = 0.02 + 4.98·e^(−5) ≈ 0.02 + 4.98×0.0067 ≈ 0.053A
Q17 HOT — RC circuit: R=1Ω, C=0.1F, vC(0)=1V [Feb 2022, Dec 2022]
RC circuit: R=1Ω, C=0.1F. Compute vC(200ms). Initial condition vC(0)=1V.
RC Transient
1
τ = RC = 1×0.1 = 0.1s = 100ms
2
x(∞): if no source → capacitor fully discharges → vC(∞) = 0V.
3
vC(t) = 0 + (1−0)·e^(−t/0.1) = e^(−t/0.1)
vC(200ms) = e^(−0.2/0.1) = e^(−2) ≈ 0.135V
💡 e^(−2) ≈ 0.135. Keep this in memory. τ=100ms, t=200ms → 2τ.
Q18 RC with voltage source: R=10Ω, C=0.2mF [Dec 2022]
RC circuit: R=10Ω, C=0.2mF=0.0002F, E source. Compute vC(500ms). vC(0)=initial value given.
RC with Source
1
τ = RC = 10×0.0002 = 0.002s = 2ms
2
x(∞): with C=open (DC steady state), no current flows through R. vC(∞) = E (all voltage drops across the open cap).
3
Apply universal formula with computed x(0), x(∞), τ.

🖥️ Exercise 4 — Analog Computing (ODE → Circuit) 🔥 8/10 exams — guaranteed since 2022
Q19 HOT — method appears in ALL exams from 2022 onward
What are the building blocks for analog computing and what does each do?
The 3 Building Blocks
1. INTEGRATOR: Vout = −(1/RC)∫Vin dt = −∫Vin dt (with RC=1s)
2. INVERTER: Vout = −Vin (Rf = Rin, unity gain with sign flip)
3. SUMMER: Vout = −Rf·(V₁/R₁ + V₂/R₂ + …) (inverted weighted sum)
★
RC=1s constraint: Messina always specifies "do not assign values to R and C, use RC=1s". This means the integrator gain is exactly 1 (no scaling).
★
Integrator circuit: C in the FEEDBACK path, R at input. (NOT the reverse — that's a differentiator!)
❌ BIGGEST TRAP: Putting C at the input and R in feedback = DIFFERENTIATOR, not integrator. Capacitor goes in FEEDBACK for integration.
Q20 HOT — d²y/dt² + 4·dy/dt + by = f(t) — "4" coefficient appears in 4+ exams
Draw the circuit for: d²y/dt² + 4·dy/dt + 6cos(4t). Use RC=1s, zero initial conditions.
From Feb 2024 exam. The "4" coefficient on dy/dt is a recurring value across 4 different exam years.
ODE → Circuit Method
1
Isolate highest derivative: ÿ = −4ẏ − 0·y + 6cos(4t) [note: no y term here, just ÿ and ẏ]
2
Signal chain: ÿ → [Int1] → −ẏ → [Inv1] → +ẏ → [Int2] → −y → [Inv2] → +y
3
Summer inputs: feed +ẏ with gain 4 (for −4ẏ term) and the forcing function −6cos(4t).
4
Summer: Rf/R_ẏ = 4 → if Rf=4Ω, R_ẏ=1Ω. Forcing term gain=6: Rf/R_f=6 → R_f=Rf/6.
Blocks: OA1(Summer) → OA2(Int1) → OA3(Inv1) → OA4(Int2) → OA5(Inv2) = y(t)
❌ Forcing term sign: the summer is inverting. To get +6cos(4t) at the output, feed −6cos(4t) into the summer. If only +cos(4t) is available, add an inverter on the input branch.
Q21 HOT — d²y/dt² + 4·dy/dt + 4·y = 2cos(2t) [June 2022, Dec 2022]
Draw the circuit for: d²y/dt² + 4·dy/dt + 4·y = 2cos(2t). RC=1s, initial conditions zero.
This exact ODE (or very similar) appears in June 2022 AND Dec 2022 — extremely HOT.
Full Setup for this HOT ODE
1
Rearrange: ÿ = −4ẏ − 4y + 2cos(2t)
2
Summer needs: +ẏ (gain 4), +y (gain 4), and −2cos(2t) (gain 2 but negated input)
3
Choose Rf = 4Ω (LCM of 4 and 4). Then: R_ẏ = 4/4 = 1Ω, R_y = 4/4 = 1Ω, R_cos = 4/2 = 2Ω
4
All integrators: R=1Ω, C=1F (RC=1s ✓)
OA1 Summer: Rf=4Ω, R₁=1Ω (+ẏ, gain4), R₂=1Ω (+y, gain4), R₃=2Ω (−cos input, gain2)
OA2: Integrator (R=1Ω, C=1F) → output: −ẏ
OA3: Inverter → output: +ẏ (feeds back to OA1 and into OA4)
OA4: Integrator → output: −y
OA5: Inverter → output: +y = Vo (also feeds back to OA1)
Q22 HOT — d²y/dt² − 4·dy/dt − 3y + 2sin(10t) [Dec 2021, Sept 2023]
Draw the circuit for: d²y/dt² − 4·dy/dt − 3y = −2sin(10t). RC=1s.
Negative coefficients! The sign handling is the key difficulty here.
Negative Coefficients — Sign Tracking
1
Rearrange: ÿ = +4ẏ + 3y − 2sin(10t)
2
Summer needs: −4ẏ into summer (so summer output = +4ẏ after inversion). Feed +ẏ × gain 4 → summer negates → −4(+ẏ)? NO. Summer output = −(Rf/R·ẏ) so to get +4ẏ, we need to feed −ẏ with gain 4.
3
Signal available: from Int1 we get −ẏ directly. Feed that with gain 4 into the summer → summer outputs −(4·(−ẏ)) = +4ẏ ✓. No need for Inv1!
4
Similarly for +3y: use −y from Int2 with gain 3 → summer outputs +3y ✓.
OA1 uses: −ẏ (directly from Int1) with gain 4, −y (directly from Int2) with gain 3, +sin input with gain 2
No inverters needed! Int1 and Int2 outputs used directly.
❌ When coefficients are POSITIVE in the ODE, you can sometimes skip the inverters by using the integrator output directly (which already has a sign flip).
📏 Circuit Fundamentals — Theory Questions 📖 Summary-based (from Q&A PDF pages 74–83)
Q23Definition — appears in written exams
What is the difference between an ideal independent source and an ideal dependent source?
Independent vs Dependent Sources
★
Independent source: provides a fixed V or I regardless of anything else in the circuit. Symbol: circle.
★
Dependent source: its V or I is controlled by a voltage or current elsewhere in the circuit. Symbol: diamond. 4 types: VCVS, CCVS, VCCS, CCCS.
❌ Dependent sources are NEVER killed when finding Rth. Only independent sources are killed (V→short, I→open).
Q24HOT — Wye-Delta: formula recalled in exam theory section
Write the Wye-to-Delta and Delta-to-Wye conversion formulas for resistors Ra, Rb, Rc ↔ R1, R2, R3.
Wye-Delta Conversion
Δ → Y: R1 = (Rb·Rc)/(Ra+Rb+Rc)
R2 = (Ra·Rc)/(Ra+Rb+Rc)
R3 = (Ra·Rb)/(Ra+Rb+Rc)

Y → Δ: Ra = (R1R2 + R2R3 + R1R3)/R1
Rb = (R1R2 + R2R3 + R1R3)/R2
Rc = (R1R2 + R2R3 + R1R3)/R3
💡 Balanced: RY = RΔ/3 or RΔ = 3RY. Star (Y) = series-like, Delta = parallel-like.
Q25KCL and KVL sign conventions
State KCL and KVL and give the sign conventions used in this course.
KCL and KVL
★
KCL: algebraic sum of currents INTO a node = 0. Current away from node = negative in node equations.
★
KVL: algebraic sum of voltages around any closed loop = 0. Walk clockwise: +E if you cross − before + (gain). −E if you cross + before − (drop). For resistors: −Ri if walking in direction of current.
Q26HOT — Equivalent resistance appeared in Nov 2024 exam
Calculate equivalent resistance RAB for a mixed series-parallel network with R₁=6Ω, R₂=5Ω, R₃=2Ω, R₄=5Ω, R₅=3Ω, R₆=6Ω, R₇=4Ω. [Nov 2024]
Method — Systematic Reduction
1
Identify series groups (same current) and parallel groups (same voltage).
2

Q27BJT Transistor — appeared in Feb 2024 CLE exam
For a BJT transistor (NPN): write the key equations relating IB, IC, IE and β.
BJT Key Equations
IC = β·IB
IE = IB + IC = IB + β·IB = (1+β)·IB
VCE = VCC − VE (where VE = IE·RE)
VCB = VC − VB
★
3 terminals: Emitter (E), Base (B), Collector (C). Two types: NPN and PNP.
💡 β (beta) is the current gain. Typical values: 50–200. IC ≈ β·IB always.
Q28HOT — Maximum Power Transfer theorem
State the Maximum Power Transfer theorem. What is the condition for maximum power to the load RL?
Maximum Power Transfer
Condition: RL = RTH (load resistance = Thevenin resistance)
Pmax = VTH² / (4·RTH)
★
The load RL receives maximum power when RL equals the Thevenin resistance seen from its terminals.
★
At maximum power: half the power from the source goes to RTH, half to RL.
