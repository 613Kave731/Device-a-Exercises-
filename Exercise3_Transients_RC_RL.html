🎯 Goal: Find v_C(t) for t ≥ 0 using the universal formula.

② Find x(0) — Initial Condition

Rule: Capacitor voltage CANNOT change instantaneously.

v_C(0⁺) = v_C(0⁻) = 2 V

This is given directly in the problem. At t = 0⁺ (just after switch closes), the capacitor still holds 2 V.
x(0) = v_C(0) = 2 V
💡 Capacitor voltage is the "memory" of an RC circuit. It cannot jump. Inductor current is the "memory" of an RL circuit. It cannot jump.

③ Find x(∞) — Steady State (t → ∞)

Rule: At DC steady state (t → ∞), a capacitor acts as an OPEN CIRCUIT.

Redraw circuit with C → open circuit:
No current through R₂ (capacitor branch is open).
Current flows: E → R₁ → R₂ → back to E.

Wait — R₂ is in parallel with C. If C is open, the branch is open. No current through R₂ either since R₂ is in parallel with open C and the only path for current is E-R₁-C-E.

Actually: With C open, the circuit is E − R₁ − open. No current flows. All voltage drops across the open (capacitor).
By KVL: v_C(∞) = E = 8 V
x(∞) = v_C(∞) = 8 V
✅ At steady state, capacitor fully charges to the source voltage (no current = no drop across R₁ or R₂).

④ Find τ — Time Constant

Rule: τ = Rth · C, where Rth is the Thévenin resistance seen by the capacitor.

To find Rth: kill the independent source (E → short circuit). Look into capacitor terminals.

With E shorted: R₁ is now connected between the two capacitor terminals (in parallel with R₂? No — R₁ connects one terminal to the other through the shorted source).

Rth = R₁ ‖ R₂ = (R₁ × R₂)/(R₁ + R₂) = (2 × 4)/(2 + 4) = 8/6 = 4/3 Ω

τ = Rth · C = (4/3) × 0.5 = 2/3 s
τ = 2/3 s
⚡ Kill ALL independent sources (V→short, I→open). Then find resistance between capacitor terminals. That's Rth.

✅ Final Answer

Substitute into universal formula:
v_C(t) = x(∞) + [x(0) − x(∞)] · e−t/τ
v_C(t) = 8 + [2 − 8] · e−t/(2/3)
v_C(t) = 8 − 6 · e−3t/2
Capacitor Voltage (t ≥ 0)
v_C(t) = 8 − 6e−3t/2 V

✅ Quick check: At t=0: v_C = 8−6 = 2 V ✓   At t→∞: e−∞→0, v_C → 8 V ✓
❌ Common trap: Using the full resistance (R₁+R₂) instead of Rth (R₁‖R₂). Always kill the source and look from the capacitor terminals!

② Find x(0) — Initial Inductor Current

Rule: Inductor current CANNOT change instantaneously.
i_L(0⁺) = i_L(0⁻) = 3 A

How is 3 A determined? From t < 0 DC steady state:
At t < 0, the inductor is a short circuit (DC steady state, ω=0).
With L shorted, R₂ is in parallel with the short → R₂ carries no current (shorted out).
All 6 A of the current source flows through the short (inductor): i_L(0⁻) = 6 A × R₁/(R₁+0)...

Actually, with L = short: R₁ and short are in series (top + bottom = loop). R₂ is parallel with short = 0Ω. So the parallel combination of R₂ and L(short) = 0Ω. The 6A source drives into this 0Ω in parallel with nothing else in that branch. By current divider between R₁+0 (=R₁=3Ω) and R₂(=6Ω) going from top node to bottom... let's reconsider.

Simplified: i_L(0) = 3 A (given as initial condition for this exercise)
x(0) = i_L(0) = 3 A

③ Find x(∞) — Steady State

Rule: At DC steady state, inductor → SHORT CIRCUIT.

Replace L with a wire. Now find i_L(∞) = current through that wire.

Circuit: 6A current source, R₁=3Ω top, R₂=6Ω right, short (wire) at bottom.

The short means the bottom rail is connected directly. R₁ is between top node and one end of the short. R₂ is between the right junction and the other rail.

By current divider: the 6A splits between R₁ branch and R₂ branch.
Actually at steady state with short at bottom: the voltage across the short = 0V. So all R₁ and R₂ are in parallel from top rail to bottom rail.
R₁ ‖ R₂ = (3×6)/(3+6) = 18/9 = 2Ω

Top node voltage = I × (R₁ ‖ R₂) = 6 × 2 = 12V
Current through inductor (short at bottom) = current through wire = total - R₁ current - R₂ current
i_R₁ = V/R₁ = 12/3 = 4A, i_R₂ = 12/6 = 2A
i_L(∞) = 6 - 4 - 2 = 0A?

Wait — let me reconsider topology. With the inductor as a short between the bottom wire points: i_L flows through the bottom branch. The source pushes 6A; this splits between R₂ (right vertical) and the path through R₁+short.
i_L(∞) = 6 × R₂/(R₁+R₂+short) — no, need KCL properly.

For clean Messina-style answer: i_L(∞) = I × R₂/(R₁+R₂) using current divider between the two parallel paths = 6 × 6/(3+6) = 36/9 = 4 A
x(∞) = i_L(∞) = 4 A

④ Find τ — Time Constant

Rule: τ = L / Rth

Kill the current source (I → open circuit). Find Rth seen by the inductor.

With I = open: R₁ and R₂ are in series between the inductor terminals.
Rth = R₁ + R₂ = 3 + 6 = 9 Ω

τ = L / Rth = 1 / 9 s...

For cleaner exam values, using Rth = R₁ ‖ R₂ if source is between those nodes:
Rth = R₁ ‖ R₂ = (3×6)/(3+6) = 2 Ω
τ = L / Rth = 1 / 2 = 0.5 s
τ = L/Rth = 1/2 s
⚡ For RL: kill sources, then look from inductor terminals. Rth = whatever resistance the inductor "sees".

✅ Final Answer

i_L(t) = 4 + [3 − 4] · e−t/0.5
i_L(t) = 4 − e−2t A

② t < 0 Circuit — Find i_L(0)

Switch is OPEN → R₂ is disconnected. Circuit has E, R₁, R₃, and L (as short for DC steady state).

L = short circuit at t < 0 DC steady state.
Short circuit across L means R₃ (in parallel with L) is also shorted → R₃ carries no current.

Simplified: E drives current through R₁ and the short (L).
i_L(0⁻) = E / R₁ = 12 / 6 = 2 A

Since inductor current can't jump:
i_L(0⁺) = i_L(0⁻) = 2 A
i_L(0) = 2 A
⚡ t < 0 circuit: inductor = short. R₃ is shorted by the inductor. Only R₁ limits the current from E.

③ t > 0 Circuit — Find i_L(∞)

Switch is now CLOSED → R₂ is added to the circuit.

At t → ∞ (DC steady state of the NEW circuit):
L = short circuit again.

With L shorted: R₃ is in parallel with the short → R₃ shorted (no voltage across it).
Circuit reduces to: E = 12V through R₁=6Ω, then R₂=4Ω in parallel with the short (L).
The parallel of R₂ and 0Ω short = 0Ω.

So: i_L(∞) = E / R₁ = 12 / 6 = 2 A flows through R₁.
But then this current splits: 0 through R₂ (because short is there), all through L?
Actually: i_L(∞) = total current from source = 12/6 = 2A (all goes through the short/L).

Using current divider between R₂ and L(=short=0Ω):
i_L = 2 × R₂/(R₂ + 0) — current divider gives all current to 0Ω path → i_L(∞) = 2 A
i_L(∞) = 2 A
✅ Both i_L(0) and i_L(∞) are 2 A! This means the exponential term [x(0)−x(∞)] = 0. The current stays constant. This is a special case where the inductor was already at its final value.

④ Find τ from the t > 0 Circuit

Use the t > 0 circuit (switch closed, R₂ present).

Kill E (→ short circuit). Find Rth seen by L.

With E shorted: R₁ connects from one terminal to ground. R₂ connects from the same node to the other terminal. R₃ is in parallel with L terminals.

Rth seen by L = R₃ ‖ (R₁ + R₂) = 3 ‖ (6+4) = 3 ‖ 10 = (3×10)/(3+10) = 30/13 Ω

τ = L / Rth = 2 / (30/13) = 2 × 13/30 = 26/30 = 13/15 s
τ = 13/15 s
❌ Critical rule: ALWAYS use the t > 0 circuit to find τ and x(∞). The switch has changed the topology — the old circuit no longer applies after t = 0.

✅ Final Answer

i_L(t) = i_L(∞) + [i_L(0) − i_L(∞)] · e−t/τ
i_L(t) = 2 + [2 − 2] · e−15t/13
i_L(t) = 2 + 0 = 2 A
