⚡ The 3 Golden Rules — G Matrix (Node Analysis)

Gii = Σ G at node i
Sum ALL conductances connected to node i (diagonal)
Gij = −G between i and j
ALWAYS negative — conductance directly between nodes i and j
bi = +I into node, −I out
Current sources: + if flowing INTO node i, − if OUT
⚡ Speed Rule: Draw the circuit, label each conductance G = 1/R. Diagonal = sum everything at the node. Off-diagonal = grab the G between those two nodes and put a minus sign. Done.
❌ Most Common Trap: Forgetting the minus sign on off-diagonal entries. G12 is ALWAYS negative (unless it's zero).
✅ Voltage source from node to ground: That node's voltage is KNOWN. Remove that row from the matrix and substitute the value into remaining equations.

🎯 Goal: Find node voltages VA and VB.

② Label Conductances G = 1/R

G₁ = 1/R₁ = 1/2 S  |  G₂ = 1/R₂ = 1/4 S  |  G₃ = 1/R₃ = 1/5 S
💡 Convert ALL resistors to conductances first. Work only with G values in the matrix — no 1/R fractions mid-row!

③ Build the G Matrix — Apply the 3 Rules

Node A diagonal GAA: Sum of all conductances at A = G₁ + G₂ = 1/2 + 1/4 = 3/4
Node B diagonal GBB: Sum of all conductances at B = G₂ + G₃ = 1/4 + 1/5 = 9/20
Off-diagonal GAB = GBA: −G₂ = −1/4 (ALWAYS negative)
Source vector: bA = +I₁ = +3 (into A), bB = −I₂ = −2 (out of B)
⎡ 3/4   −1/4 ⎤   ⎡ VA ⎤   =   ⎡ +3 ⎤
⎣ −1/4   9/20 ⎦   ⎣ VB ⎦   =   ⎣ −2 ⎦

④ Solve the System

Multiply through by 20 to clear fractions:

15 VA − 5 VB = 60    (row 1 × 20)
−5 VA + 9 VB = −40    (row 2 × 20)

From row 1: 3 VA − VB = 12 → VB = 3VA − 12

Substitute into row 2:
−5 VA + 9(3VA − 12) = −40
−5 VA + 27VA − 108 = −40
22 VA = 68
VA = 68/22 = 34/11 ≈ 3.09 V

Then: VB = 3(34/11) − 12 = 102/11 − 132/11 = −30/11 ≈ −2.73 V

✅ Final Answer

Node A Voltage
VA = 34/11 ≈ 3.1 V
Node B Voltage
VB = −30/11 ≈ −2.7 V
⚡ Key insight: Node B is NEGATIVE because the 2A current source is draining it while only G₂ feeds it from A. Negative node voltages are completely valid!
❌ Common trap: Writing bB = +2 instead of −2. Current flowing OUT of a node is NEGATIVE in the source vector.

② Identify Known Node — Remove Its Row

Node A has a voltage source to ground → VA = 8 V (known!)

We only need to solve for VB and VC.

Original 3×3 system: Remove row A, but keep VA = 8 in the source vector when it appears in other rows.
⚡ Rule: When a node is connected to ground through a voltage source, that node's voltage equals the source voltage. Delete its matrix row. Any G connecting A to another node moves to the SOURCE vector (right-hand side) of that row.

③ Build Reduced 2×2 Matrix

Node B diagonal GBB: G₁ + G₂ + G₃ = 1/4 + 1/6 + 1/3 = 3/12 + 2/12 + 4/12 = 9/12 = 3/4
Node C diagonal GCC: G₃ + G₄ = 1/3 + 1/5 = 5/15 + 3/15 = 8/15
Off-diagonal GBC = GCB: −G₃ = −1/3
Source vector bB: G₁ × VA = (1/4)(8) = 2 (A feeds B through G₁)
Source vector bC: +I = +2 A (into C)
⎡ 3/4   −1/3 ⎤   ⎡ VB ⎤   =   ⎡ 2 ⎤
⎣ −1/3   8/15 ⎦   ⎣ VC ⎦   =   ⎣ 2 ⎦

④ Solve

Multiply row 1 by 12: 9 VB − 4 VC = 24
Multiply row 2 by 15: −5 VB + 8 VC = 30

From row 1: VC = (9VB − 24)/4

Sub into row 2:
−5VB + 8·(9VB − 24)/4 = 30
−5VB + 18VB − 48 = 30
13VB = 78 → VB = 6 V

VC = (9×6 − 24)/4 = (54−24)/4 = 30/4 = 7.5 V

✅ The known-node trick reduced a 3×3 to a 2×2. Always look for voltage-source-to-ground nodes first — they give you free voltages!
❌ Trap: Moving G₁·VA to the wrong sign. When VA feeds node B through G₁, it adds +G₁·VA to bB (it acts like a current injection).

② What Is a Supernode?

A voltage source between two unknown nodes A and B creates a SUPERNODE.

Problem: You can't write a normal KCL equation at A or B separately — you don't know the current through the ideal voltage source.

Solution: Merge A and B into one "super-node". Write ONE combined KCL + ONE constraint.
Supernode → Merged KCL (currents leave A or B = currents entering A or B)
+ Constraint: VA − VB = E_source
⚡ Speed Rule: Draw a bubble enclosing both nodes A and B. Write KCL for currents crossing the bubble boundary. Add the voltage constraint. 2 equations, 2 unknowns.

③ Write Merged KCL + Constraint

KCL for the Supernode (current into bubble = current out of bubble):

Currents IN: I₁ = 4A (into A)
Currents OUT: G₁·VA (through R₁ to ground) + G₂·VB (through R₂ to ground) + I₂ = 2A (out of B)

4 = G₁·VA + G₂·VB + 2
4 = (1/3)VA + (1/6)VB + 2
(1/3)VA + (1/6)VB = 2    ← Equation 1

Constraint equation:
VA − VB = 6    ← Equation 2

④ Solve

From Eq 2: VA = VB + 6

Substitute into Eq 1:
(1/3)(VB + 6) + (1/6)VB = 2
(1/3)VB + 2 + (1/6)VB = 2
(2/6 + 1/6)VB = 0
(3/6)VB = 0
VB = 0 V

Then: VA = 0 + 6 = 6 V

✅ Final Answer

Node A
VA = 6 V
Node B
VB = 0 V
✅ VB = 0 V makes physical sense: the I₁ current feeding A exactly balances the drop across G₁, while I₂ draining B exactly balances what comes through G₂. The voltage source enforces the 6V difference.
❌ Supernode trap: Students sometimes forget the constraint equation and only write KCL — that gives 1 equation with 2 unknowns (unsolvable). You ALWAYS need both.

⚡ The 3 Golden Rules — R Matrix (Mesh Analysis)

Rii = Σ R in mesh i
Sum ALL resistors in mesh i (diagonal)
Rij = −R shared between i and j
ALWAYS negative — resistor shared between mesh i and j
bi: +E clockwise, −E counterclockwise
Walk clockwise around mesh i; + if source pushes you forward
⚡ Speed Rule: Draw ALL mesh currents clockwise. Diagonal = total R in that loop. Off-diagonal = grab the shared R and negate. Check source polarity walking clockwise.
❌ Most Common Trap: Off-diagonal sign error — R12 is ALWAYS negative.
✅ Supermesh: Current source between two meshes → merge the outer KVL loop + constraint (ij − ii = Isource). Exactly like supernode but for meshes.

② Draw Clockwise Mesh Currents

Mesh 1 (left loop): i₁ clockwise
Contains: E₁, R₁, R₂

Mesh 2 (right loop): i₂ clockwise
Contains: R₂, R₃, R₄, E₂

Shared element: R₂ is in BOTH meshes → becomes the off-diagonal term.
⚡ Always draw ALL mesh currents in the SAME direction (clockwise). This makes the off-diagonal always negative.

③ Build R Matrix

R₁₁ = R₁ + R₂ = 4 + 2 = 6 Ω
R₂₂ = R₂ + R₃ + R₄ = 2 + 6 + 3 = 11 Ω
R₁₂ = R₂₁ = −R₂ = −2 Ω

Source b₁: Walk clockwise in mesh 1: E₁ = +10V (pushes i₁ forward) → b₁ = +10
Source b₂: Walk clockwise in mesh 2: E₂ at right branch, + terminal at top, walking up = against i₂ → b₂ = −6
(E₂ pushes current upward on right side, but i₂ flows downward there — so it opposes → negative)
⎡ 6   −2 ⎤   ⎡ i₁ ⎤   =   ⎡ +10 ⎤
⎣ −2   11 ⎦   ⎣ i₂ ⎦   =   ⎣ −6 ⎦

④ Solve

From row 1: 6i₁ − 2i₂ = 10 → 3i₁ − i₂ = 5 → i₂ = 3i₁ − 5

Substitute into row 2:
−2i₁ + 11(3i₁ − 5) = −6
−2i₁ + 33i₁ − 55 = −6
31i₁ = 49
i₁ = 49/31 ≈ 1.58 A

i₂ = 3(49/31) − 5 = 147/31 − 155/31 = −8/31 ≈ −0.26 A

✅ Final Answer

Mesh 1
i₁ = 49/31 ≈ 1.58 A
Mesh 2
i₂ = −8/31 ≈ −0.26 A
⚡ Negative i₂ just means the actual current flows counterclockwise in mesh 2. That's fine — the sign is part of the answer!
❌ Trap: Getting b₂ sign wrong. Always walk clockwise and use + if the source helps you, − if it fights you.

Mesh 1: E₁, R₁, R₂, R₅ — shared R₂ with mesh 2
Mesh 2: R₂, R₃, R₄ — shared R₂ with mesh 1, shared R₄ with mesh 3
Mesh 3: R₃, R₄, E₂ — shared R₄ with mesh 2

③ Build the 3×3 R Matrix

R₁₁ = R₁+R₂+R₅ = 3+4+6 = 13 Ω
R₂₂ = R₂+R₃+R₄ = 4+5+2 = 11 Ω
R₃₃ = R₃+R₄ = 5+2 = 7 Ω (note: R₃ not shared, I'll correct — R₃ appears in mesh 2 top and mesh 3 top; R₄ shared 2&3)
R₁₂ = R₂₁ = −R₂ = −4    R₁₃ = R₃₁ = 0    R₂₃ = R₃₂ = −R₄ = −2

b₁ = +12V (E₁ aids i₁ clockwise) | b₂ = 0 | b₃ = −8V (E₂ opposes i₃ clockwise)
⎡ 13   −4   0 ⎤   ⎡ i₁ ⎤   =   ⎡ +12 ⎤
⎢ −4   11   −2 ⎥   ⎢ i₂ ⎥   =   ⎢ 0 ⎥
⎣ 0   −2   7 ⎦   ⎣ i₃ ⎦   =   ⎣ −8 ⎦

④ Solve by Substitution

From row 3: −2i₂ + 7i₃ = −8 → i₂ = (7i₃ + 8)/2

From row 2: −4i₁ + 11i₂ − 2i₃ = 0 → i₁ = (11i₂ − 2i₃)/4

Substitute into row 1 with i₂ = (7i₃+8)/2:
i₁ = (11(7i₃+8)/2 − 2i₃)/4 = (77i₃+88−4i₃)/(8) = (73i₃+88)/8

Row 1: 13·(73i₃+88)/8 − 4·(7i₃+8)/2 = 12
(949i₃+1144)/8 − (28i₃+32)/2 = 12
(949i₃+1144 − 112i₃ − 128)/8 = 12
837i₃ + 1016 = 96
837i₃ = −920
i₃ ≈ −1.099 A

i₂ = (7(−1.099)+8)/2 = (−7.693+8)/2 ≈ 0.154 A
i₁ = (11(0.154)−2(−1.099))/4 = (1.694+2.198)/4 ≈ 0.973 A

✅ Final Answer

Mesh 2
i₂ ≈ 0.15 A

✅ 3×3 matrix follows the same rules as 2×2 — diagonal positive, off-diagonal negative, zero if no shared element.

② What Is a Supermesh?

When a current source sits between two meshes (i₁ and i₂), you cannot write KVL for each mesh separately — you don't know the voltage across the current source.

Solution: Merge i₁ and i₂ into a supermesh. Write ONE outer KVL loop skipping the current source + ONE constraint equation.
Supermesh: Outer KVL (skip current source branch)
+ Constraint: i₂ − i₁ = Iₛ (if Iₛ flows from mesh 1 to mesh 2)
⚡ Supermesh = Supernode of Mesh Analysis. Same concept: merge + constraint. If the current source flows from i₁ toward i₂: i₂ − i₁ = Iₛ.

③ Write Outer KVL + Constraint

Outer KVL (clockwise, skip Iₛ branch):
Start at bottom-left, go clockwise: E₁ rises → +10V, R₁ drops → −R₁·i₁ = −4i₁, R₂ drops → −R₂·i₂ = −6i₂, R₄ drops → −R₄·i₂ = −3i₂, R₃ drops → −R₃·i₁ = −5i₁

10 − 4i₁ − 6i₂ − 3i₂ − 5i₁ = 0
10 − 9i₁ − 9i₂ = 0
9i₁ + 9i₂ = 10    ← Equation 1

Constraint (Iₛ flows downward = from mesh 2 side to mesh 1 side):
Current source = i₂ − i₁ = 3    ← Equation 2

④ Solve

Eq 2: i₂ = i₁ + 3

Sub into Eq 1:
9i₁ + 9(i₁ + 3) = 10
9i₁ + 9i₁ + 27 = 10
18i₁ = −17
i₁ = −17/18 ≈ −0.94 A

i₂ = −17/18 + 3 = −17/18 + 54/18 = 37/18 ≈ 2.06 A

✅ Final Answer

Mesh 1
i₁ = −17/18 ≈ −0.94 A
Mesh 2
i₂ = 37/18 ≈ 2.06 A
✅ Check constraint: i₂ − i₁ = 37/18 − (−17/18) = 54/18 = 3 ✓ Correct!
❌ Supermesh trap: Getting constraint direction wrong. Iₛ flows FROM mesh 1 side TO mesh 2 side → i₂ − i₁ = Iₛ. If it flows the other way: i₁ − i₂ = Iₛ. Draw it carefully!
⚡ Always verify: Substitute back into constraint equation to confirm. Takes 5 seconds and catches sign errors.
