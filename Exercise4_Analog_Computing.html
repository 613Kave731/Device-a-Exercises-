Σ

① The Differential Equation

ẏ + 3y = 2x(t)
where x(t) is the input signal  |  y(t) is the output (voltage)  |  ẏ = dy/dt
This is a first-order ODE. There is one derivative (ẏ), so we need one integrator.

Goal: Build an op-amp circuit whose output voltage y(t) satisfies this equation for any input x(t).
⚡ First step always: Isolate the highest-order derivative on the left:
ẏ = 2x(t) − 3y
This tells you exactly what signals you need to SUM to produce ẏ.

✅ Verify — Trace Signal Flow

Assume OA3 output is y(t). Trace backwards:

OA3 output = +y  →  OA3 input (−y) = OA2 output
OA2 output = −∫(ẏ)dt = −y  →  OA2 input = ẏ = OA1 output
OA1 (inverting summer): output = −(Rf/R_y · y + Rf/R_x · x(t))
    = −(3/1 · y + 3/1.5 · x) = −3y − 2x

Wait — but we need ẏ = −3y + 2x. Let me check the input sign to the summer.
If x(t) enters as −x(t) (negated), then: output = −(3y + 2·(−x)) = −3y + 2x = ẏ ✓

Solution: feed −x(t) into the summer (x goes through an inverter first, or connect directly with correct polarity from the source).
Circuit reconstructs the ODE
ẏ = −3y + 2x(t)  →  ẏ + 3y = 2x(t) ✓
✅ Always verify by tracing the signal flow end-to-end. If any sign is wrong, add an inverter on that branch.
❌ Most common mistake: Forgetting that the inverting summer NEGATES. Every block has a built-in sign flip. Track signs at every node or you'll get the wrong ODE.

① The Differential Equation

ÿ + 4ẏ + 3y = 0
Homogeneous 2nd-order ODE  |  ÿ = d²y/dt²  |  ẏ = dy/dt
This is a second-order ODE. There are two derivatives (ÿ and ẏ), so we need two integrators.

Rearrange to isolate the highest derivative:
ÿ = −4ẏ − 3y
⚡ Rule: Order of ODE = number of integrators needed. 1st order → 1 integrator. 2nd order → 2 integrators. nth order → n integrators.

① The Differential Equation

ÿ + 5ẏ + 6y = 2x(t)
2nd-order forced ODE  |  x(t) = forcing input  |  y(t) = output voltage
Rearrange: ÿ = −5ẏ − 6y + 2x(t)

Three terms to sum: −5ẏ, −6y, and +2x(t).
Need: 2 integrators + 1 summer + track signs carefully.

Trick: Use OA2 (first integrator) output directly as −ẏ and OA4 output as −y. Feed these with appropriate gains into the summer — the summer negates, so feeding −ẏ with gain 5 gives −(5·(−ẏ)) = +5ẏ... wait, we need −5ẏ. So we need +ẏ with gain 5. Use inverter after first integrator.
⚡ Exam shortcut: For the forced term 2x(t), just add x(t) as another input to the summer with appropriate gain. You don't need an extra block — the summer handles it.

⚡ Exam speed tip: The Rf value = LCM of all denominators you need for the gains. Here gains are 5, 6, 2 → Rf = 30Ω works. Then R_k = Rf / gain_k.
❌ Top mistake: Students draw the integrator with R in feedback and C at input — that's a DIFFERENTIATOR. The capacitor goes in FEEDBACK, resistor at INPUT for an integrator. Double-check this every time.
