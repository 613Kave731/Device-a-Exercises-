⚡ Golden Rules — Op-Amp Analysis

Rule 1 — Virtual Short: V₋ = V₊
The two input terminals are at the same potential
Rule 2 — Virtual Open: I₋ = I₊ = 0
No current flows INTO the op-amp terminals
Millman at Node A (V₋):
V_o = −R_f · Σ(Eₖ/Rₖ ± Iₖ)
Set Millman numerator = 0 (virtual ground) → solve for V_o
⚡ Method: V₊ = 0 (non-inverting to ground) → Virtual Short → V₋ = 0. Node A is at virtual ground. Write Millman numerator = 0 at Node A. Solve for V_o.

① The Circuit

ElementValueRole
E₁4 VInput branch 1 → through R₁ to Node A
R₁2 ΩInput resistor branch 1
E₂6 VInput branch 2 → through R₂ to Node A
R₂3 ΩInput resistor branch 2
Rf10 ΩFeedback resistor (A → V_o)
V₊0 VNon-inverting input tied to ground

② Apply Golden Rules

Step 1 — Virtual Short: V₋ = V₊ = 0 V (V₊ is grounded)
→ Node A is at 0 V (Virtual Ground)

Step 2 — Virtual Open: No current enters V₋ terminal
→ All current from E₁ through R₁ + all current from E₂ through R₂ must flow through Rf to V_o

Step 3 — KCL at Node A (Millman numerator = 0):
Sum of all currents arriving at A = 0 (no current goes into the op-amp)
✅ Because V₊ = 0 → V₋ = 0, Node A is a virtual ground. Millman numerator set to zero gives us V_o directly.

③ Write Millman Equation at Node A

Currents arriving at Node A (VA = 0):

From E₁ through R₁:  (E₁ − 0)/R₁ = 4/2 = 2 A (into A)
From E₂ through R₂:  (E₂ − 0)/R₂ = 6/3 = 2 A (into A)
From V_o through Rf:  (V_o − 0)/Rf = V_o/10 (into A from output side)

KCL at A: sum = 0
E₁/R₁ + E₂/R₂ + V_o/Rf = 0
2 + 2 + V_o/10 = 0
💡 The feedback resistor current direction: V_o flows back to Node A through Rf. Since V_A = 0, the current is V_o/Rf (can be negative if V_o is negative).

④ Solve for V_o

2 + 2 + V_o/10 = 0
V_o/10 = −4
V_o = −40 V

Alternatively, using the Millman formula directly:
V_o = −Rf · (E₁/R₁ + E₂/R₂) = −10 · (4/2 + 6/3) = −10 · (2 + 2) = −40 V
V_o = −R_f · Σ(Eₖ/Rₖ)
This is the inverting summer formula

✅ Final Answer

Output Voltage
V_o = −40 V
⚡ Physical intuition: Both inputs push positive current into Node A. The op-amp drives V_o very negative to pull that current back through Rf and maintain V_A = 0.
❌ Common trap: Forgetting the minus sign. An inverting op-amp INVERTS. If the inputs are positive, V_o is negative.

💡 A current source connected directly to the Millman node adds its value directly to the numerator. Check the direction: INTO node = positive, OUT of node = negative.

E₁/R₁ + E₂/R₂ + Iₛ + V_o/Rf = 0

10/5 + 4/2 + 1 + V_o/6 = 0

⚡ Current sources enter the Millman numerator directly (no 1/R factor). Voltage sources enter as E/R.

④ Solve for V_o

V_o/6 = −5
V_o = −30 V

Formula check:
V_o = −Rf · (E₁/R₁ + E₂/R₂ + Iₛ) = −6 · (2 + 2 + 1) = −6 · 5 = −30 V ✓

✅ Final Answer

Output Voltage
V_o = −30 V
✅ The current source adds directly: it's as if a third voltage branch with E=R·I had been added, but here we just add 1 A directly to the KCL sum.
❌ Sign trap: If Iₛ flows OUT of Node A, it's −Iₛ in the equation. Always draw the arrow and check the direction relative to Node A.

① Two-Stage Cascade Circuit

StageInputsRf
Stage 1 (OA1)E₁=6V via R₁=3Ω  |  E₂=4V via R₂=4ΩRf₁ = 8Ω
Stage 2 (OA2)V_o1 via R₃=4ΩRf₂ = 4Ω

② Solve Stage 1 — Find V_o1

Apply golden rules to OA1:
V₊₁ = 0 → V₋₁ = 0 → Node A₁ = 0 V (virtual ground)

KCL at A₁:
E₁/R₁ + E₂/R₂ + V_o1/Rf₁ = 0
6/3 + 4/4 + V_o1/8 = 0
2 + 1 + V_o1/8 = 0
V_o1/8 = −3
V_o1 = −24 V

③ Solve Stage 2 — V_o1 as Input

Apply golden rules to OA2:
V₊₂ = 0 → V₋₂ = 0 → Node A₂ = 0 V (virtual ground)

Stage 2 has ONE input: V_o1 = −24V through R₃ = 4Ω

KCL at A₂:
V_o1/R₃ + V_o/Rf₂ = 0
−24/4 + V_o/4 = 0
−6 + V_o/4 = 0
V_o/4 = 6
V_o = +24 V

④ Verify the Sign Logic

Stage 1 is an inverting amplifier → flips sign: V_o1 = −24V
Stage 2 is also an inverting amplifier → flips sign again: V_o = +24V

Two inversions = net non-inverting!
V_o = −Rf₂/R₃ · V_o1 = −(4/4)·(−24) = −1·(−24) = +24 V
⚡ Key insight: Cascaded inverting stages → (−1)·(−1) = +1. If both stages have equal Rf and input R, V_o = +V_in to stage 1. This is how you build a non-inverting amplifier from inverting stages!

✅ Final Answer

Stage 1 Output
V_o1 = −24 V
Final Output
V_o = +24 V
✅ Two-stage cascade strategy: Solve left stage first (virtual ground at A₁ → find V_o1). Then treat V_o1 as a regular voltage source feeding Stage 2. Apply same Millman method.
❌ Most common cascade mistake: Forgetting that V_o1 enters Stage 2 AS AN INPUT (through R₃). It's not a Rf — it's an input branch. Treat it exactly like E₁ or E₂ in Exercise A.
